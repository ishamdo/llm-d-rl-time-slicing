🔄 Section 5: Dynamic Preemption Handshake Timeline
T+0s — 120s: Shadow vLLM holds lock (queue depth=0). Batch inference client completes queries at 100% throughput.
T+120.0s: RL Trainer calls acquire(). Orchestrator increments queue depth to 1.
T+120.2s: Shadow vLLM supervisor detects preemption signal, issues SIGTERM to stock vLLM, releasing GPU memory (<200ms).
T+120.5s: RL Trainer acquires lock immediately, executing GPU backpropagation (20s). Once finished, vLLM auto-resumes!
